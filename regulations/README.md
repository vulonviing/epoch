# Regulations

This directory contains three official legal PDFs needed by the tabular use
cases. Their exact sources and file hashes are recorded in
`SOURCE_MANIFEST.md`.

The UC4 document corpus is not shipped. EFRAG-derived standards, comparison
helpers, images, raw API responses, and supporting documents remain local-only
because no explicit redistribution permission was established for this release.
See `esrs/README.md` for the expected local layout.

The repository's Apache License applies to project-authored code and
documentation. It does not relicense the official legal texts.
