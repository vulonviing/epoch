# Siemens FY2025 Sustainability Statement — local source required

This repository does not redistribute Siemens report text or extracted pages.
Public availability and attribution alone do not establish permission to copy
the report into a separate software repository.

UC4 expects a locally supplied Markdown corpus in this directory, including:

```text
index/esrs_index.md
```

and the report sections referenced by that index. Obtain the FY2025 report from
Siemens through a lawful source and prepare the local corpus for your own use.
All files other than this README are gitignored. Do not commit them.

The public code can be installed and the tabular UC1–UC3 cases can be tested
without this corpus. UC4 integration tests are marked `external_corpus` and are
skipped when the documented local sources are absent.

Source landing page: <https://www.siemens.com/global/en/company/sustainability/reports.html>
