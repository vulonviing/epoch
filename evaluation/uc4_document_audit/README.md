# UC4 document-audit disclosure

UC4 was audited through repeated, source-grounded review of the deterministic
document mapping, two blind-pass classification pairs, the RD3 join, three
persona assessments, and the final reconciliation.

The raw packets, findings JSON, reports, model records, and frozen gold are not
published because they reproduce or quote Siemens and EFRAG source material for
which this release has no explicit redistribution grant. This directory records
the method and omission; it does not claim that attribution substitutes for
permission.

Authorized researchers can reproduce the audit locally after supplying the
corpus described in `data/siemens_sustainability_2025/README.md` and
`regulations/esrs/README.md`, then applying `evaluation/TAXONOMY.md`.
