# Peer-review publication boundary

The fixed reviewer rubric and anonymized aggregate scores are the complete
public peer-review release. Individual forms, PDFs, comments, identities,
initials, timestamps, and source deliverables are withheld because the public
release has no consent basis for redistributing them.

The aggregates preserve the evaluative result while preventing attribution to
an individual reviewer. No "anonymized individual form" exists in this repo;
`AGGREGATE_RESULTS.md` is the intentionally conservative publication unit.
